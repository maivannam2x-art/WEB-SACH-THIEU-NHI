# Cánh Giấy — Website giới thiệu thương hiệu

Website one-page quảng bá thương hiệu sách thiếu nhi **Cánh Giấy**.

## Nội dung đáp ứng yêu cầu đồ án

- Văn bản và nhận diện thương hiệu với logo chữ thiết kế riêng.
- Hình ảnh được trích từ video quảng bá Cánh Giấy.
- Ảnh động WebP dùng trong phần giới thiệu trải nghiệm đọc sách.
- Video 30 giây có âm thanh/lồng tiếng và phụ đề hiển thị trực tiếp trong video.
- Thiết kế responsive cho desktop, tablet và mobile.
- Hiệu ứng chuyển động, marquee, floating cards và parallax nhẹ.

## Triển khai

Dự án là website tĩnh, không cần build. Có thể deploy trực tiếp trên Vercel với root directory là thư mục gốc repository.
